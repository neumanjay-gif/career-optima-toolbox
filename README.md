# Career Optima Toolbox — Browser Extension

**Your elite job search concierge.** Find the right jobs and save time with AI-powered tools, cover letters, outreach searches, and more.

---

## About

Career Optima Toolbox is a companion browser extension for the Career Optima desktop application — your AI-powered job search assistant.

Browse any job board and instantly evaluate whether a posting is worth your time. Get Pursue / Possible / Pass ratings, match scores, and compensation analysis based on your own resume and criteria. Generate personalized cover letters and outreach messages in seconds. Track every application in one place.

**Key Features:**
- **Intelligent Job Evaluation** — Instantly analyze any job posting against your resume. Get Pursue/Possible/Pass ratings, match scores, and compensation analysis.
- **AI-Powered Cover Letters** — Generate personalized cover letters in seconds, tailored to each job and your writing style.
- **Resume Optimization** — Get specific suggestions to reframe your resume for each opportunity.
- **Application Tracking** — Track companies, roles, status, and salary ranges in one place.
- **Works Everywhere** — Integrates with LinkedIn, Indeed, Glassdoor, and 100+ job boards.
- **Privacy-First** — Your data stays on your device. Nothing is shared back to Career Optima.

## Installation

### Download from GitHub
You can install the extension directly from this repository:

1. Download the latest release from the [Releases](../../releases) page
2. Follow the instructions for your browser:
   - **Chrome:** Go to `chrome://extensions`, enable Developer Mode, click **Load unpacked**, and select the downloaded folder
   - **Edge:** Go to `edge://extensions`, enable Developer Mode, click **Load unpacked**, and select the downloaded folder
   - **Firefox:** Go to `about:debugging`, click **This Firefox**, then **Load Temporary Add-on**, and select the downloaded `.zip` file
   - **Safari:** Follow the instructions included in the Safari release package
